# KM Drive

KM Drive 用户软件的下载与更新。

- 下载：打开本页右侧的 **Releases**，下载最新版本的 `KMDrive-x.y.z.exe`，双击运行即可，不需要安装。
- 更新：软件启动时会自动检查新版本；也可以在软件的「关于」页点「检查更新」。有新版本时会显示版本号和更新内容，确认后自动下载并更换。
- 更新记录：见 [CHANGELOG.md](CHANGELOG.md)。

本仓库只存放发布文件和更新说明，不含源代码。
